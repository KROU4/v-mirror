# V-Mirror

**V из Cyberpunk 2077, похожий на настоящего человека.** V-Mirror — веб-копия редактора внешности игры (патч 2.5, оба типа тела). Приложение смотрит на фотографию и подсказывает вариант для каждой строки: кожа, причёска и цвет волос, глаза, нос, рот, челюсть, уши, брови, борода, макияж и остальное. Номера совпадают с теми, что вы выставляете в игре.

**Сайт:** https://krou4.github.io/v-mirror/ · [English](../README.md)

## Возможности

- **Копия редактора.** Все строки, число вариантов, порядок и зависимости игрового редактора для мужского и женского V: у каждой причёски свой набор цветов, у бороды сначала стиль, потом цвет. Каталог извлечён из файлов самой игры.
- **Фото → настройки.**
  - MediaPipe замеряет лицо прямо в браузере.
  - Мультимодальная модель на [OpenRouter](https://openrouter.ai) по вашему выбору подбирает ближайший вариант в каждой строке.
  - На выходе список «строка X — вариант N», который вы переносите в игру.
- **Живая 3D-модель V** (по желанию, нужен [набор ресурсов](#живое-3d-набор-ресурсов)). Модель собирается из мешей, текстур и анимаций редактора игры. Как в игре:
  - камера под каждую строку и свет;
  - моргание, улыбка с зубами, морфы;
  - волосы, бороды, макияж, тело целиком.
- **Образцы цветов из игры.** В строках цветов показываются игровые миниатюры: градиенты волос, фото радужки, нейл-арт. Без набора ресурсов рисуется близкое CSS-приближение по данным о цветах.
- **Два языка.** Русский и английский, переключатель в шапке.
- **Без сервера.** Это статический сайт: ключ OpenRouter и фотографии остаются в вашем браузере.

## Скан фото и ключ OpenRouter

У сайта нет бэкенда, и ваш ключ он не видит.

1. Создайте ключ на [openrouter.ai/keys](https://openrouter.ai/keys). Бесплатные модели со зрением подходят.
2. Откройте окно ключа из шапки или кнопку **Ключ и модель** в скане фото. Вставьте ключ и нажмите **Проверить ключ**.
3. Выберите модель (бесплатные идут первыми) и запустите скан.

Ключ хранится только в браузере и уходит только на `openrouter.ai`. Адрес `github.io` у сайта общий с другими страницами, поэтому по умолчанию ключ живёт только до закрытия вкладки. Чтобы ключ сохранялся, поставьте галочку «Запомнить ключ на этом устройстве».

Ключа нет? Откройте вкладку **Ручной ответ**: скопируйте промпт, отправьте его вместе с фото в любой чат с мультимодальной моделью и вставьте её JSON-ответ обратно.

## Живое 3D: набор ресурсов

3D-модель строится из ресурсов самой Cyberpunk 2077. Они принадлежат CD PROJEKT RED, поэтому их **нет** ни в репозитории, ни на публичном сайте. Набор ресурсов вы один раз собираете из своей копии игры и подключаете его папку в браузере. Сборка идёт на Windows, занимает 5–10 минут, набор весит 560–800 МБ. Страница читает файлы прямо с диска и никуда их не отправляет.

**Одна команда.** Откройте PowerShell и выполните:

```powershell
irm https://krou4.github.io/v-mirror/pack.ps1 | iex
```

Скрипт сам находит игру (GOG, Steam, Epic или просмотр дисков; папка игры только читается), ставит Node.js и Python через winget, если их нет (Python — для вашего пользователя; установщик Node.js ставит его на весь компьютер, поэтому Windows один раз спросит разрешение), скачивает исходники V-Mirror того коммита, из которого собран сайт, собирает набор в `Документы\V-Mirror pack` (или в `%LOCALAPPDATA%\v-mirror\pack`, если папки «Документы» нет) и открывает V-Mirror с готовой панелью набора. Нажмите **Выбрать папку набора** и укажите эту папку (путь уже в буфере обмена). Браузер её запомнит.

**Ручная сборка** (из клона): `npm install`, затем `npm run pack` (или `npm run pack -- --game "D:\Games\Cyberpunk 2077" --out "D:\v-mirror-pack"`), либо двойной щелчок по `tools\pack-windows.cmd`. Параметры и что делать, если не получилось (политика выполнения, нет winget, антивирус, место на диске): [ASSET_PACK.md](ASSET_PACK.md).

Без набора работает всё, кроме живого 3D: каталог, скан фото, список настроек, образцы цветов и портреты V.

| Клавиша | Действие |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | строка |

| <kbd>C</kbd> | скопировать список |
| <kbd>L</kbd> | ссылка на персонажа |
| <kbd>Esc</kbd> | закрыть сетку или скан |

## Разработка

Нужен Node.js 20+.

```sh
npm install
npm run dev        # dev-сервер; если есть tools/local, берёт набор ресурсов оттуда
npm test           # тесты (vitest)
npm run build      # проверка типов, сборка и проверка, что в dist нет файлов игры
npm run preview    # просмотр собранной версии
```

`VITE_BASE` задаёт базовый путь сборки. Для GitHub Pages это `/v-mirror/`. Для 3D при разработке соберите набор в `tools/local`: эта папка не попадает в git.

Каждый пуш в `main` запускает [`pages.yml`](../.github/workflows/pages.yml). Он прогоняет тесты, собирает сайт, проверяет, что в сборке нет файлов игры, и публикует на GitHub Pages.

## Ограничения

- По фронтальному фото форма носа и челюсти читается хуже, чем глаза и рот, поэтому уверенность в этих строках ниже. Лучше всего работает снимок анфас при ровном свете.
- Цвета в игре зависят от света редактора. Подбор идёт по игровым образцам, а не по финальному рендеру.
- Набор ресурсов собирается только на Windows.
- Физика болтающихся костей не моделируется.

## Правовое

Неофициальный фанатский проект. Он не связан с CD PROJEKT RED и не одобрен ею. Cyberpunk 2077 и связанные названия — товарные знаки CD PROJEKT S.A. В репозитории нет файлов игры. Есть только производные данные (списки вариантов, цвета образцов, числовые признаки) и портреты-скриншоты. Собранный набор ресурсов остаётся у вас; не распространяйте его.
